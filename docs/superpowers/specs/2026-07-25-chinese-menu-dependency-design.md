# 中文菜单与按需依赖安装设计

## 目标

将 RS Manager 的交互式入口改为中文数字菜单；执行各功能前先检查该功能所需组件，缺失时由用户确认后安装。修复未安装 Sing-box 时添加 VLESS/AnyTLS 只报 Reality 密钥错误的问题。

## 范围

- 不实现或展示 Web 面板。
- 保留现有 `rs` 命令行子命令，保证脚本调用方式兼容。
- 主菜单提供 Realm 转发、Sing-box 协议、BBR/TCP 调优、服务管理、诊断、更新与退出。
- Realm 和 Sing-box 各自使用中文数字子菜单，覆盖当前已有的增删改查、端口段、克隆和链接功能。
- BBR/TCP 子菜单提供状态查看、智能一键调优、预览、Realm 专项调优与还原。

## 依赖处理

每个会真正使用服务二进制的菜单操作均通过同一个交互辅助函数处理依赖：

1. 检测对应二进制是否可用。
2. 若已安装，继续当前操作。
3. 若缺失，显示组件名称并询问“是否立即安装 [Y/n]”。
4. 确认后调用已有的受校验组件安装流程；安装成功后继续原操作。
5. 拒绝或安装失败时取消本次操作，并显示可复制的手动安装命令。

Sing-box 的“添加协议”和“克隆协议”必须先确保 Sing-box 已安装。命令行直接调用 `rs singbox add` 不自动下载，但会返回明确错误：`sing-box is not installed; run: rs service install sing-box`。

智能一键调优先检测内核版本、可用拥塞控制算法、当前拥塞控制与队列算法、内存与文件描述符限制；输出拟应用的兼容参数并等待用户确认。仅在确认后写入配置，始终保留现有的预览与还原能力。若 BBR 不受内核支持，则不伪装为启用成功，并给出检测结果。

## 错误与安全

- 不在用户未确认时下载或安装组件。
- 不自动重启 VPS、不修改 SSH、DNS 或防火墙。
- 保留安装器的已有校验、服务部署与事务回滚逻辑。
- 菜单只负责交互编排；底层命令保留严格、可脚本化的行为。
